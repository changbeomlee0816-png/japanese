# Tabi — 여행 계획 앱

일정을 대충 적어 넣으면 이동 경로·비용·현지 맛집까지 정리해 주고, 여행 당일에는 실시간으로
지금 어디쯤인지 알려주는 여행 계획 웹앱입니다. iOS 스타일 인터페이스로 만들었습니다.

```bash
npm install
npm run dev             # http://localhost:5173
npm run build           # dist/ — GitHub Pages 등 정적 호스팅용
npm run build:single    # dist-single/index.html — 단일 파일 (Supabase 배포용)
npm run build:artifact  # dist-artifact/tabi.html — Claude Artifact용 단일 파일
```

---

## 링크 하나로 같이 보기 (Supabase)

`npm run build`로 만든 앱을 GitHub Pages에 올리고, 일정은 Supabase에 저장합니다.
링크를 받은 사람은 **계정 없이 주소만으로** 열어볼 수 있고, 일정을 고치면 그 화면에도 자동으로 반영됩니다.

### 링크 구조

```
보기 링크   https://<도메인>/japanese/?t=<일정 id>
수정 링크   https://<도메인>/japanese/?t=<일정 id>#k=<수정 토큰>
```

수정 토큰은 URL 프래그먼트(`#`)에 담습니다. 프래그먼트는 서버로 전송되지 않아 호스팅 서버 로그에 남지 않고,
앱은 토큰을 받는 즉시 브라우저에 저장한 뒤 **주소창에서 지웁니다**. 그래서 주소창을 그대로 복사해
공유해도 수정 권한이 새어 나가지 않습니다. 다른 기기에서 편집하려면 설정 → 공유 링크 →
`수정 링크 보기`에서 따로 복사하세요.

### 데이터 모델과 권한

```sql
trips(id uuid, edit_token uuid, title text, data jsonb, updated_at timestamptz)
```

`trips` 테이블은 RLS를 켜고 **정책을 하나도 두지 않습니다**. 따라서 공개 키(anon)로는 테이블을
직접 읽거나 쓸 수 없고, `security definer` 함수 세 개로만 접근합니다.

| 함수 | 하는 일 | 필요한 것 |
|---|---|---|
| `trip_get(id)` | 일정 읽기 (edit_token은 반환하지 않음) | 링크의 uuid |
| `trip_head(id)` | 변경 시각만 확인 (폴링용) | 링크의 uuid |
| `trip_create(title, data)` | 링크 만들기, 수정 토큰 발급 | — (시간당 100건 제한) |
| `trip_save(id, token, title, data)` | 저장 | uuid + 수정 토큰 |

그래서 `.env.production`에 커밋된 anon 키는 **공개돼도 되는 값**입니다. 보안은 키가 아니라
"uuid를 알아야 읽고, 토큰까지 맞아야 쓴다"는 규칙이 지킵니다.
Supabase 보안 린터가 `rls_enabled_no_policy`와 `anon_security_definer_function_executable`을
경고로 띄우는데, 둘 다 이 설계의 의도된 결과입니다.

> 링크의 uuid를 아는 사람은 누구나 일정을 볼 수 있습니다(이른바 unlisted 링크).
> 민감한 내용은 넣지 마세요.

### 반영 방식

- 수정하면 1.8초 뒤에 한 번으로 묶어 저장합니다.
- 보는 쪽은 15초마다 변경 시각만 확인하고, 바뀌었을 때만 전체를 받아옵니다.
  탭을 다시 열거나 창에 포커스가 돌아오면 즉시 확인합니다.
- 수정 권한이 있는 화면에서 다른 기기의 변경이 감지되면, 편집 중인 내용을 덮어쓰지 않도록
  자동 반영 대신 `최신본 불러오기` 버튼을 띄웁니다.
- 남의 링크를 열어도 **내 로컬 일정은 그대로 남습니다.** 공유 링크의 일정은 별도 캐시
  (`tabi.shared.<id>`)에 저장되고, `이 링크에서 나가기`를 누르면 원래 내 일정으로 돌아옵니다.

### 배포 — 호스팅은 별도로 필요합니다

Supabase는 **데이터만** 담당합니다. 앱 파일(HTML/JS/CSS)은 다른 곳에 올려야 합니다.

> **Supabase로 앱을 서빙할 수는 없습니다.** `*.supabase.co` 게이트웨이가 피싱 방지를 위해
> 모든 HTML 응답을 `content-type: text/plain` 으로 바꾸고
> `content-security-policy: default-src 'none'; sandbox` 를 붙입니다.
> Storage 공개 버킷도, 엣지 함수도 마찬가지입니다. (확인 완료 — 시도했다가 되돌린 경로입니다)

**GitHub Pages를 쓰려면 저장소가 공개여야 합니다.** 무료 플랜에서는 비공개 저장소에
Pages를 쓸 수 없어(`Create Pages site failed: Resource not accessible by integration`)
현재 워크플로는 실패합니다. 저장소를 공개로 바꾸거나 GitHub Pro로 올리면
`.github/workflows/deploy.yml`이 그대로 동작하고, 주소는
`https://changbeomlee0816-png.github.io/japanese/` 가 됩니다.

`npm run build:single`이 만드는 `dist-single/index.html` 은 파일 하나로 완결되어 있어,
정적 파일 하나만 올릴 수 있는 곳이면 어디든 그대로 쓸 수 있습니다.

Supabase 프로젝트는 무료 티어라 약 1주일간 접속이 없으면 자동으로 일시정지됩니다.
그때는 Supabase 대시보드에서 재개해야 링크가 다시 열립니다.

## Claude Artifact로 공유하기 (대안)

`npm run build:artifact`가 만드는 단일 HTML을 Claude Artifact로 발행하면, 링크를 연 모든 사람이
**같은 최신 일정**을 봅니다. 원리는 간단합니다.

- 일정 데이터는 발행된 문서 안(`<script id="app-state">`)에 들어 있고, 문서는 자기 소스도 함께 갖고 있습니다.
- 일정을 고치면 페이지가 상태만 갈아끼운 **새 버전을 스스로 발행**합니다 (`artifact` 런타임 기능).
- 열려 있는 모든 화면이 새 버전으로 새로고침됩니다. 보던 탭·날짜·스크롤 위치는 그대로 복원됩니다.
- 저장은 편집이 멈춘 뒤 2.5초에 한 번으로 묶어서 하고, 시트를 열어 편집하는 동안에는 미룹니다.
  네비게이션 바의 칩(`저장됨` / `공유본에 저장`)으로 지금 상태를 알 수 있고, 눌러서 즉시 저장할 수도 있습니다.

**권한에 따라 화면이 달라집니다.**

| | 편집 권한 있음 | 보기 전용 |
|---|---|---|
| 일정 수정 | 가능, 저장하면 모두에게 반영 | 편집 UI 없음 (첫 저장 시도에서 감지) |
| 지도·맛집·비용·PDF | 전부 사용 가능 | 전부 사용 가능 |
| 구글맵 API 키 | 각자 브라우저에만 저장 | 각자 브라우저에만 저장 |

**공유되는 것은 여행 일정뿐입니다.** 구글맵 API 키를 비롯한 설정은 발행 문서에 들어가지 않고
각자의 브라우저에만 남습니다.

직접 호스팅한 경우(`npm run build`)에는 공유 기능 없이 기존처럼 이 브라우저에만 저장됩니다.

## 기능

### 1. 대충 적은 일정을 넣으면 이동·비용을 계산

일정 탭 → **일정 붙여넣기**에 메모를 그대로 붙여넣으면 날짜·시각·체류시간·비용을 알아서 읽습니다.

```
9/12
10:00 나리타공항 도착
12:30 아사쿠사 센소지 (90분)
14:30 도쿄 스카이트리 2100엔
저녁 시부야 이자카야
```

- 날짜: `9/12`, `2026-09-12`, `9월 12일`, `Day 1`, `1일차`, `둘째날`
- 시각: `10:00`, `오후 2시`, `아침`/`점심`/`저녁`/`체크인`
- 체류시간: `(90분)`, `[2시간]`, `1시간 30분`
- 비용: `2100엔`, `¥1,500`, `12000원`
- 분류(관광/식사/카페/쇼핑/숙소/이동/액티비티)는 이름에서 추론합니다

가져오기를 누르면 각 장소의 좌표를 찾아 채우고, 연속된 두 장소 사이의 **이동수단·소요시간·거리·요금**을
자동으로 계산합니다. 이동수단은 구간마다 도보/대중교통/택시로 바꿀 수 있습니다.

### 2. 지도로 보는 동선

지도 탭에서 그날의 방문지가 순서대로 표시되고, 구간 경로가 선으로 이어집니다.
**구글 지도에서 오늘 동선 열기**를 누르면 출발지·경유지·목적지가 채워진 상태로 구글 지도 길찾기가 열려
실제 환승 시각과 실시간 교통 상황을 확인할 수 있습니다.

### 3. 근처 현지인 맛집

맛집 탭에서 기준 장소를 고르면 반경(500m~3km) 안의 식당을 보여줍니다.
평점·리뷰 수·가격대로 계산한 **현지인 지수** 순으로 정렬되며, 일정 카드의 `주변 맛집` 버튼으로
그 장소 기준 추천으로 바로 넘어갑니다.

### 4. PDF 저장

오른쪽 위 프린터 아이콘 → **PDF로 저장**. 표지(총 비용 요약) + 날짜별 시간표 +
구간별 이동 정보 + 그날 동선 주변 맛집 추천이 담긴 A4 문서가 나옵니다.
브라우저 인쇄 기능을 쓰기 때문에 한글이 벡터로 저장돼 깨끗합니다.

인쇄 창이 뜨지 않는 환경(공유 링크가 프레임 안에서 열린 경우 등)을 위해
**일정표 HTML 파일 내려받기**도 함께 제공합니다. 받은 파일을 열고 인쇄하면 같은 PDF가 나옵니다.

### 5. 실시간 일정 추적

여행 당일에는 일정 탭 상단에 지금 진행 중인 일정, 남은 시간, 다음 일정까지의 카운트다운이 뜹니다.

- 이동에 걸리는 시간을 계산해 **지금 출발해야 할 때** 알려줍니다 (설정에서 몇 분 전에 알릴지 조절)
- 계획보다 밀리면 `N분 밀기` 한 번으로 이후 일정을 통째로 조정합니다
- 장소 도착 시 `도착`을 누르면 실제 시각이 기록되고 계획 대비 지연이 표시됩니다
- 브라우저 알림을 켜면 출발 시각에 알림이 옵니다

### 6. 일정은 얼마든지, 언제든 수정

날짜와 항목 수에 제한이 없습니다. 카드를 끌어 순서를 바꾸면 시각이 다시 배분되고,
탭하면 이름·장소·시각·체류시간·비용·메모를 고치거나 다른 날짜로 옮길 수 있습니다.
날짜 단위로 복제·삭제·통째로 시간 이동도 됩니다. 여행 자체도 여러 개 만들어 전환할 수 있습니다.

### 7. 애플 스타일

iOS 시스템 컬러, SF Pro/Pretendard 조합, 반투명 블러 내비게이션·탭 바, 큰 제목,
아래에서 올라오는 시트, 세그먼티드 컨트롤과 토글 스위치. 라이트/다크 모드를 모두 지원하며
설정에서 고정할 수 있습니다.

## 구글 지도 연동

**키 없이도 앱 전체가 동작합니다.** 이 경우 내장 장소 사전(일본 주요 도시 80여 곳)과
큐레이션한 맛집 목록을 쓰고, 이동 시간·요금은 거리 기반 추정치로 계산합니다. 화면에도 "추정"으로 표시됩니다.

실제 경로와 실시간 데이터를 쓰려면 설정 탭에 Google Maps API 키를 넣으세요.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 생성
2. **Maps JavaScript API**, **Places API (New)**, **Directions API** 활성화
3. 사용자 인증 정보 → API 키 생성 → **HTTP 리퍼러 제한**을 앱 도메인으로 걸어두기
4. 설정 탭 → API 키 입력 → 저장

키를 넣으면 이렇게 바뀝니다.

| | 키 없음 | 키 있음 |
|---|---|---|
| 장소 검색 | 내장 사전(일본 주요 장소) | 전 세계 Google Places |
| 지도 | 좌표 기반 개략도 | 실제 지도 + 경로 폴리라인 |
| 이동 시간·경로 | 거리 기반 추정 | Directions API 실측, 환승 노선 안내 |
| 요금 | 통화권별 요금 모델 추정 | 제공 구간은 실제 운임, 나머지는 추정 |
| 맛집 | 내장 큐레이션 | 주변 실제 식당 + 평점·리뷰·영업시간 |

키는 브라우저(localStorage)에만 저장되며 다른 곳으로 전송되지 않습니다.
Directions 호출은 세션 캐시를 두어 같은 구간을 반복 조회하지 않습니다.

## 알아두면 좋은 것

- **공유 링크를 만들기 전까지는 모든 데이터가 이 브라우저에만 저장됩니다.** 계정도 로그인도 없습니다.
  기기를 옮기거나 백업하려면 설정 → 백업 파일 내보내기/가져오기를 쓰세요.
- **공유 링크를 만들면 그 여행 일정만** Supabase에 올라갑니다. 구글맵 API 키를 포함한 설정은
  서버로 보내지 않고 각자 브라우저에만 남습니다.
- **비용은 추정치입니다.** 교통비는 통화권별 요금 체계를 근사한 모델(일본 지하철 기본요금,
  거리 비례 가산, 장거리 철도 별도 계산 등)로 계산합니다. 숙박비와 항공권은 포함되지 않습니다.
- **현지인 지수는 추정 지표입니다.** 평점·리뷰 수·가격대로 계산한 값이며 실제 손님 구성과 다를 수 있습니다.
- 키가 없을 때 쓰이는 내장 맛집 목록은 참고용 큐레이션입니다. 영업시간과 가격은 바뀔 수 있으니
  방문 전 확인하세요.
